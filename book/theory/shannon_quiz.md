> 题型参照上海高考数学卷 · 满分 100 分 · 建议完成时间 30 分钟。

## 考生注意

1. 本试卷由三道大题组成：填空题、选择题、解答题。答案均写在题后空白处。
2. 本卷所有对数均以 2 为底，记为 log₂；信息量单位为"比特"。
3. 可以使用计算器。近似值参考：log₂3 ≈ 1.585，log₂6 ≈ 2.585。

**【本卷涉及的公式，均已用文字给出】**

- 信息量：一个概率为 p 的事件，其信息量 = −log₂p（比特）。事件越不可能，信息量越大。
- 熵（平均信息量）：把每个符号的信息量按出现概率加权求和，即 H = p₁·log₂(1/p₁) + p₂·log₂(1/p₂) + ……（各项之和）。
- 链式法则：整条消息的概率等于各符号（条件）概率相乘，所以整条消息的信息量等于各符号信息量相加。

（2）（4 分）设一条 3 字母消息由相互独立的字母组成，概率分别为 1/2、1/4、1/4。求消息"abc"的概率、信息量，并验证它等于三个字母各自信息量之和（链式法则）。

（3）（10 分）证明题：设某分布共有 n 个可能取值，概率为 p₁, p₂, ……, pₙ（均大于 0，且总和为 1），熵 H = p₁·log₂(1/p₁) + p₂·log₂(1/p₂) + …… + pₙ·log₂(1/pₙ)。

①（3 分）证明 H ≥ 0，并指出等号成立的条件；

②（7 分）证明 H ≤ log₂n（以 2 为底 n 的对数），且等号成立当且仅当 p₁ = p₂ = …… = pₙ = 1/n（即均匀分布的熵最大）。

> 提示：先证明引理"对任意 x > 0，ln x ≤ x − 1"（令 f(x) = x − 1 − ln x，讨论其单调性即可）；再取 x = 1/(n·pᵢ) 代入引理，两边同乘 pᵢ 后对所有 i 求和，利用"各项概率之和为 1"与"n 个 1/n 之和为 1"化简。

# 参考答案与解析

## 一、填空题

1. **8**。ASCII 每字符固定 8 比特，这是视频开头所说的"默认编码相当低效"。

2. **0**。信息量 = −log₂1 = 0。必然事件不提供任何信息。

3. **3**。−log₂(1/8) = log₂8 = 3 比特。

4. **1；3**。"上"：−log₂(1/2) = 1 比特；"左"：−log₂(1/8) = 3 比特。

5. **下、下**。位流 1010 按码字切分为 10 | 10，两个 10 都是"下"。解码规则是：机器人从头读入，一旦凑成一个完整码字就立刻登记一条指令（这正是前缀码保证的"无须分隔符"）。

6. **2**。log₂4 = 2，且四个码字长度均为 2 时（如 00、01、10、11）没有空间浪费，平均码长恰好等于熵 2 比特。

7. **＋**（加）。独立事件概率相乘，取负对数后信息量相加。

8. **1**。1950 年《印刷英语的预测与熵》实验：被试拥有至少 100 个字符上下文时，英语熵约每字符 1 比特——每个字符平均只值一个"是/否"答案。

## 二、选择题

| 题号 | 1 | 2 | 3 | 4 |
|:---:|:---:|:---:|:---:|:---:|
| 答案 | C | B | C | B |

1. **C**。均匀分布熵最大：C 的熵 = 4 × (1/4 × log₂4) = 2 比特；A 为 1 比特；B 约 0.47 比特；D 为 1.75 比特。

2. **B**。0、10、110、111 互不为前缀。A 中 0 是 01 的前缀；C 中 1 是其余全部的前缀；D 中 0 是 01、011 的前缀。若有前缀冲突，机器人无法确定位流在哪里划断。

3. **C**。这正是无损编码定理（Shannon 1948 年开创信息论的论文）的结论：熵是下界，且可被任意逼近。A 反了（概率越大信息量越小）；B 反了（随机噪声不可压缩）；D 错（前缀码恰恰允许码字长短不一）。

4. **B**。"头在云端的学生"论证：若压缩是完美的，输出位流与随机噪声不可区分，于是所有 n 位位流等可能，反推出所有被压缩消息等可能；任何"更省"的改动都会在别处付出更大代价。

## 三、解答题

**1.**

（1）"上"：−log₂(1/2) = 1 比特；"下"：−log₂(1/4) = 2 比特；"左"：−log₂(1/8) = 3 比特；"右"：−log₂(1/8) = 3 比特。

（2）H = 1/2 × 1 + 1/4 × 2 + 1/8 × 3 + 1/8 × 3 = 0.5 + 0.5 + 0.375 + 0.375 = **1.75 比特**。（验证：这也是"聪明学生"编码的平均码长。）

（3）平均码长 = 1/2 × 1 + 1/4 × 2 + 1/8 × 3 + 1/8 × 3 = 1.75 比特 = H。

它是完美的：本例每个概率都是 2 的负整数次幂（1/2 = 2⁻¹，1/4 = 2⁻²，1/8 = 2⁻³），码字 0、10、110、111 的长度恰好等于对应符号的信息量（1、2、3、3 位）。而信息量就是完美压缩下应分配的比特数（概率为 p 的消息应分配 −log₂p 位），所以平均码长恰好压到熵——既不可能更低（定理），又恰好达到。

**2.**

（1）随机噪声中每个比特都独立且等概率（1/0 各 50%），没有任何可预测结构，也就没有可压缩的冗余。反过来看：设压缩后的位流长度为 n，若它真与随机噪声不可区分，则全部 2ⁿ 个可能的 n 位位流必须等可能；若底下的消息并非等可能，则接收端一眼就能看出这不是噪声（某些位流更常见）。所以完美压缩意味着：被压缩的 2ⁿ 条消息本身必须等可能，每条概率恰为 1/2ⁿ = 2⁻ⁿ。此时码长 n = −log₂p，恰好等于信息量。

（2）二叉树第 2 层共有 4 个节点（00、01、10、11），代表全部两位位流。给消息 A 用 1 位码字 0 后，任何以 0 开头的位流都必须另作他用（否则 0 会成为它们的前缀），于是第 2 层的节点 00 和 01 被整体"吃掉"、禁止使用。剩下的 3 条消息只剩 10、11 两个第 2 层节点可用：其中之一占掉一个后，最后两条消息都被挤到第 3 层（110、111）。

（3）平均码长 = (1 + 2 + 3 + 3)/4 = 9/4 = **2.25 比特**，大于等长两位编码的 2 比特。省下 1 位（A 从 2 位变 1 位），却迫使两条消息各多付 1 位（从 2 位变 3 位），净损失 1 位——这正是"在毯子上按下鼓包，它必在别处鼓得更高"：等可能消息最有效率的编码就是全部等长。

**3.**

（1）ASCII：10000 × 8 = **80000 比特**；变长码：10000 × 4 = **40000 比特**；熵率极限：10000 × 1 = **10000 比特**。压缩比 80000 : 10000 = **8 : 1**。即理论上英语在充分使用上下文后，每字符平均只需约 1 比特。

（2）P(abc) = (1/2) × (1/4) × (1/4) = **1/32**；信息量 = −log₂(1/32) = **5 比特**。各字母信息量为 1、2、2 比特，相加恰得 5 比特。对数把概率的乘法变成信息量的加法，所以整条消息的信息量等于各符号信息量之和（链式法则），这也是"把各符号分数信息量累加得到整条消息编码长度"的根据。

（3）

① 对每个 i：pᵢ > 0，且 1/pᵢ ≥ 1（因为 pᵢ ≤ 1），所以 log₂(1/pᵢ) ≥ 0，每一项 pᵢ·log₂(1/pᵢ) ≥ 0，相加得 **H ≥ 0**。等号当且仅当每一项都为 0，即所有 pᵢ = 1——只有一个取值（必然事件）的退化分布。

② 先证引理：令 f(x) = x − 1 − ln x（x > 0），求导得 f′(x) = 1 − 1/x。当 0 < x < 1 时 f′ < 0，当 x > 1 时 f′ > 0，故 f 在 x = 1 处取得最小值 f(1) = 0，即 **ln x ≤ x − 1**，等号当且仅当 x = 1。

在引理中取 x = 1/(n·pᵢ)（> 0），得 ln(1/(n·pᵢ)) ≤ 1/(n·pᵢ) − 1，即 ln(1/pᵢ) ≤ ln n + 1/(n·pᵢ) − 1。两边同乘 pᵢ 后对所有 i 求和（即对 ln(1/pᵢ) 作加权平均，再除以 ln2 换成以 2 为底）：

H = p₁·log₂(1/p₁) + …… + pₙ·log₂(1/pₙ) ≤ log₂n + [1/(n·ln2) + …… + 1/(n·ln2)] − [p₁ + …… + pₙ]/ln2

其中 n 个 1/(n·ln2) 相加等于 1/ln2，而各项概率之和为 1，故第二、三项相抵为 0，得 **H ≤ log₂n**。

等号成立当且仅当引理对每一个 i 都取等，即 1/(n·pᵢ) = 1，即 **pᵢ = 1/n 对一切 i 成立**。证毕。

（直观印证：这解释了"分布越均匀熵越大""固定符号数时均匀分布熵最大"，也呼应选择题第 1 题与判断题中的相关结论。）

## 附加思考题参考思路

- 预训练的目标是最小化交叉熵损失；交叉熵正是"按模型给出的概率分布设计理想编码时的平均码长"（模型概率越接近真实概率，平均码长越接近熵这个极限）。所以最小化交叉熵 = 最小化平均编码长度 = 把模型训练成一个尽可能好的压缩器。
- 由无损编码定理，熵是压缩极限；模型预测越准，编码越短。预测与压缩是一体两面。
- 香农研究英语熵的历史（n-gram 统计、请妻子 Betty 猜下一个字母、1950 年真人实验）表明：评估压缩极限必然要"探测某个智能的语言模型"——这与今天用大语言模型做编码器遥相呼应。"压缩即智能"作为口号难以严格评判（"智能"定义模糊），但"压缩的数学理论与人工智能怪异相关"则是本片立论所在。
