# 生命以负熵为食——从概率论到信息论

> 生命以负熵为食 ——薛定谔《什么是生命》

任何一个生命体，无论是硅基生命还是数字生命，底层的活动模式可以抽象为行动——信息——模型的动态三角。我们通过行动从环境中获取信息，对信息压缩、记忆、再次表达成为启发式或者模型，然后模型指导下一次更有效的行动。这个三角循环的目的是降低熵和系统的混乱无序性，使系统变得更有组织、更有智能、更长寿最后完成复制，在生命结束前留下下一代。

想象自己是一只老鼠，你可以(a)探索环境、(6)可以发现环境中的食物并吃掉它，(c)如果剩下的时间无所探索和觅食你可以休息。进化压力和环境结构会让你发展处记忆道路、避开有毒食物、快速决定分配休息、探索时间资源的有限理想。关于这个过程，Simon(1956)有非常精彩的描述：环境的随机结构是如何塑造生命体的有限理性的。

无论交易还是编程实践，无法逃脱的第一大定律就是热力学第二定律(熵增定律)，任何违反该定律的经验和窍门都会被恶狠狠地惩罚。

以编程而言，对熵增定律的应用如下：给定消息源的熵为H(x),如何巧妙地设计码长或者说定义随机变量，以达到最小化期望的目标。具体的例子有香农-法诺编码或霍夫曼编码。

以交易而言，在分布未知的情况下，通过统计方法和其他约束信息的获取，尽可能地去最大化熵。伟大的统计物理学家E.T Jaynes在1991的文章中探讨我们如何在宏观经济中应用熵这个概念：
> 或许宏观经济系统不是沿着当下理论提供的解释做出反应，或许它只是在满足自然资源约束和政府法律约束的前提下朝着熵最大化的方向演进的。

编程和交易两者一个沿着约束前提朝熵最大化演进，一个沿着给定熵的条件下最小化期望比特，势必要互相竞争合作。我所能做的就是用自己有限的理性，以“足够好”的满意而非追求“最优”为原则去让两者动态平衡。唯如此，才能在高维层次上达到互惠互利的状态，而不是在矛盾中把自己撕裂。

## 熵在投资中的应用：
投资能赚钱的基本原理是你必须更高效地帮助社会完成资源配置，起码大于平均水平。如果自己在持续地资源错配，持续地输钱，那么离开这个行当是活该的。
既然要更高效地完成资源配置工作，那就要借助资源分配的底层原理——信息论。

信息论解决的问题是：如何分配宝贵的码长，来压缩或者解压不断动态变化的底层概率分布。

信息论核心思想是两句话：

- 一件越不可能的事件(Event)发生了，它所循环的信息价值更高(这句话本身就让我们避免了很多精力与时间的错误配置，
如果能够执行的话)。
- 两件独立事件的信息可以相加。

翻译成数学公式就是：一个事件的自信息量等于其发生概率倒数的对数（以 2 为底），单位是比特：

I(E) = -log₂( P(E) )  比特

其中 P(E) 是事件 E 发生的概率。若一个事件的信息量不超过 n 比特，即 I(E) ≤ n，意味着它足以用 n 个二进制位来编码。事件越不可能（P(E) 越小），信息量越大；一个必然事件（P(E) = 1）的信息量为 0。
